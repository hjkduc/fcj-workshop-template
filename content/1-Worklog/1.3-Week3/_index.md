### Week 3 Objectives:

* Explore advanced databases and content delivery networks (CDN).
* Learn about Windows workloads on AWS and high-availability web architectures.
* Research AWS migration strategies and disaster recovery solutions.

### Week 3 Achievements:

* **Databases & Performance:** Understood NoSQL principles with DynamoDB and application acceleration using ElastiCache.
* **Network Optimization:** Mastered content distribution using CloudFront and Lambda@Edge to reduce latency at edge locations.
* **Enterprise Integration:** Learned to integrate Windows environments and Managed Microsoft AD on AWS while applying High Availability design patterns.
* **Migration & Recovery:** Mastered the tools for migrating servers (VM Import/Export) and databases (DMS, SCT), along with disaster recovery planning using AWS Elastic Disaster Recovery.

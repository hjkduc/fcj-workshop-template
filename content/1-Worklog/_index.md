**On this page**, you will find the complete worklog documenting my internship journey participating in the First Cloud Journey program. 

The program is divided into two main phases. During the first 6 weeks, I focused on exploring and mastering the AWS ecosystem. From week 7 onwards, I participated in developing a real-world project named **Wakan**, taking on the role of **Cloud Architect & Security Engineer**.

**Phase 1: Exploring and Mastering the AWS Ecosystem**
* **Week 1:** [Foundational Knowledge, Core Services (EC2, S3, VPC), and IAM Security](1.1-week1/)
* **Week 2:** [Advanced Architecture, High Availability, and Comprehensive Security](1.2-week2/)
* **Week 3:** [Operations Automation, IaC (CDK), and FinOps](1.3-week3/)
* **Week 4:** [Container Ecosystem (ECS, EKS) and DevOps CI/CD Pipelines](1.4-week4/)
* **Week 5:** [Application Modernization and Serverless Ecosystem Practices](1.5-week5/)
* **Week 6:** [Data Analytics, Data Lake, and Machine Learning](1.6-week6/)

**Phase 2: Practical Project Development (Wakan Project)**
* **Week 7:** [Architecture Definition & Project Initialization](1.7-week7/)
* **Week 8:** [Foundational Infrastructure Setup (S3, CloudFront, WAF, Cognito)](1.8-week8/)
* **Week 9:** [Business & API Security (Secrets Manager, API Gateway)](1.9-week9/)
* **Week 10:** [System Integration & Monitoring (CloudWatch, AWS Budgets)](1.10-week10/)
* **Week 11:** [Pentest, IAM Audit & Optimization](1.11-week11/)
* **Week 12:** [Finalization, Demo & Project Presentation](1.12-week12/)

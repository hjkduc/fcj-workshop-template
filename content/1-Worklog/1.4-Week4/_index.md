### Week 4 Objectives:

* Optimize systems on AWS with a focus on Operations.
* Master serverless automation and advanced monitoring techniques.
* Implement Infrastructure as Code (IaC) for resource management and deployment.

### Week 4 Achievements:

* **Serverless Automation:** Grasped the fundamentals of serverless architecture and learned how to automate operational tasks using AWS Lambda.
* **Advanced Observability:** Upgraded monitoring capabilities by integrating CloudWatch with Grafana, and completed hands-on scenarios in the Advanced CloudWatch Workshop.
* **Resource & Access Governance:** Learned best practices for organizing AWS resources using Tags and Resource Groups, and implemented strict access controls mapping IAM policies to Resource Tags.
* **Secure Operations:** Mastered AWS Systems Manager for fleet management and utilized Session Manager to securely access EC2 instances without needing open inbound ports or bastion hosts.
* **Infrastructure as Code (IaC):** Transitioned from manual console configurations to automated deployments using AWS CloudFormation and gained basic practical knowledge of the AWS Cloud Development Kit (CDK).
